# Admin360

Платформа за деловодство, счетоводство, лични картони на служителите, склад и инвентар.
Засега има общата рамка от Dams360 (ляво меню, header, footer, тъмна тема) и примерни страници;
модулите от менюто са празни страници, които ще се изграждат една по една.

## Стартиране (Windows)

```
py -m pip install -r requirements.txt
py app.py
```

Отворете http://127.0.0.1:5000

## Какво се сменя къде

| Какво | Файл |
|---|---|
| Име на проекта, надпис под логото, автор във footer-а | `config.py` (`APP_NAME`, `APP_TAGLINE`, `APP_AUTHOR`) |
| Пунктове в лявото меню | `config.py` (`MENU`) |
| Иконки за менюто | `templates/components/icons.html` |
| Знак на логото | `templates/components/brand_logo.html` |
| Цветове на темата | `static/css/app-theme.css` (токените най-горе: `--c-bg`, `--c-accent` …) |
| Карти, таблици, форми | `static/css/app-content.css` |

## Нова страница

1. Шаблон в `templates/pages/`, който започва така:

```
{% extends "layouts/app_shell.html" %}
{% set sidebar_active = 'moiat_kluch' %}
{% set header_title = 'Заглавие' %}
{% set header_breadcrumbs = [{'label': 'Начало', 'url': url_for('dashboard')}, {'label': 'Заглавие'}] %}
{% block content %}
<div class="page">
    <section class="dash-card">...</section>
</div>
{% endblock %}
```

2. Маршрут в `app.py`:

```python
@app.route("/moiata-stranica")
def moiata_stranica():
    return render_template("pages/moiata_stranica.html")
```

3. Пункт в `MENU` в `config.py`: `{"key": "moiat_kluch", "label": "Моята страница", "icon": "document", "endpoint": "moiata_stranica"}`.

Всяка страница ползва общата рамка (`layouts/app_shell.html`). Не правете страници със собствено меню.

## Данни

Данните се пазят в SQLite файл `instance/admin360.db` (създава се сам при първо стартиране и не влиза в git).
Изтрийте файла, ако искате да започнете отначало с началния списък.

## Персонал → Служители (`personnel.py`)

- Началният личен състав е в `SEED` в `personnel.py`; при първо стартиране имената и длъжностите се нормализират
  (Иван Петров Георгиев; Инженер, ХЕС).
- Подредба по длъжност: групите и редът им са в `RANK_GROUPS`; другият вариант е по азбучен ред.
- „Премахни“ не изтрива: служителят минава в „Бивши служители“ с дата и причина и може да бъде върнат.
  Всяка промяна се пази в история (`employee_events`).
- Лични картони (предстои): при напускане зачисленото имущество ще трябва да се прехвърли или бракува,
  преди служителят да бъде премахнат; мястото за това е `card_items_for()`.

## Готови елементи

- Поле за дата с български календар: `{% from "components/date_input.html" import date_input %}{{ date_input('date', today) }}`
- Филтри `bgdate` (дд.мм.гггг) и `bgnum` (десетична запетая)
- Незаписани промени: предупреждение при напускане, Ctrl+S записва, Enter минава към следващото поле в таблица (`static/js/app-ux.js`)
- Поле за файл на български („Избери файл“)

## Склад

- Складове: 1 Кричим, 2 Цанков камък (`WAREHOUSES` в `stock.py`).
- Инвентарът е в две групи: под и над прага на стойността. Прагът (сега 20 лв) се сменя от „Настройки“ в менюто на профила.
- Всяка позиция има МОЛ, свързан със служител от „Персонал“.
- Материал, който още не е получен (празно количество при импорта), е с количество 0.
- Импорт: „Склад → Наличности → Импорт“, редове `склад;МОЛ;инв. номер;наименование`, после мярка и количество в отделни колони. Позиция с еднакви склад, група, инв. номер и наименование се обновява; повторен ред в същия импорт се пропуска.
- Инвентарният номер не е уникален: един номер може да е под и над прага и на няколко различни позиции.
- Позиция се изтрива с бутона „Изтрий“ в списъка или във формата.
- Началната наличност е в `seed/`; всеки файл от `SEED_FILES` се зарежда веднъж (помни се в таблица `stock_seeds`).

## Картони

- „Персонал → Картони“: лични картони (на служител) и картони по съоръжения/помещения, в отделни списъци.
- Картонът има три раздела: инвентар, лични предпазни средства (номера 09-…) и дълготрайни активи. Със склада се свързва само инвентарът, по инвентарен номер; под и над прага са един общ списък.
- В „Наличности“: „Общо“ е счетоводното количество, „По картони“ е зачисленото, „На склад“ = общо − по картони.
- „Разминавания“ показва номерата, по които картоните надвишават общото, и инвентара по картони, който го няма в склада.
- Импорт: .xls картони (втори лист). Началните картони на Кричим са в `seed/kartoni_krichim.json`.
- Служител с невърнато имущество по картона не може да напусне.
